# Salamandra [FANGAME / GDPS]

---

## About Salamandra:

It contains mostly visual and functional elements, such as the complete server mod with textures, including:

- A separate server and space for your save files and music.
- Unlocked icons.
- Textures and other small items.
- Maintenance and update notifications.
- Custom badges.
